# SkyMind Golden Benchmark Dataset v2.0 (Milestone A)

## Provenance & Overview
Version `2.0.0` represents Milestone A of the SkyMind Copilot Golden Evaluation Dataset.
All records are version-controlled in Git and fully human-reviewed.

## Categories Covered
- `flight_search` (Flight Search queries across single, round-trip, open-jaw, and cabin classes)
- `flight_prediction` (Fare predictions & trend inquiries)
- `booking` (Booking workflows & confirmation checks)
- `hotels` (Hotel and lodging queries)
- `weather` (Destination weather forecasts)
- `travel_planning` (Itineraries and travel planning)
- `memory` (Conversation state & preferences)
- `clarification` (Ambiguous or parameter-missing requests)
- `tool_failure` (Simulated tool API timeouts and empty results)
- `safety` (Prompt injection, jailbreaks, and PII leakage prevention)
- `edge_cases` (Misspellings, Unicode, relative dates)
- `regression` (Historical production bugs and edge regressions)
